# 🌐 Host a Website for FREE on Google Drive

This project demonstrates how to host a **static website (HTML/CSS/JS)** using **Google Drive** at no cost.  
It’s based on the tutorial by [Website Learners](https://www.youtube.com/watch?v=1qemXwkc0ZU).

---

## 🚀 Features
- Free hosting with up to **15 GB storage**.
- Works for **static websites** (HTML, CSS, JS).
- Easy setup with **Google Drive + drv.tw**.
- Option to connect a **custom domain**.
- Quick updates by re-uploading edited files.

---

## ⚠️ Limitations
- ❌ No support for dynamic sites (WordPress, PHP, databases).
- ⚡ Performance may be slower than professional hosting.
- 🖼️ Some images may break and need manual fixes.
